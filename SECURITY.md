# Security policy

This repository is a research project. It deliberately contains artifacts and dependencies frozen
at the time of the study (2025), some of which now have known vulnerabilities: do not use them in
production.

The `MavenBuildDiversity/experiments/hijack-sim/` folder simulates a dependency hijacking attack.
Its modules are inert: they only contain a marker file, no malicious code.

## Reporting an issue

If you find an exposed secret or a security issue in the scripts, please do not open a public
issue: use the **"Report a vulnerability"** button in this repository's **Security** tab (private
GitHub disclosure).
